## Рилсы «без видео» (17.10.2026) - причина найдена и починена
- Это были фотопосты и карусели под ссылкой /reel/ (yt-dlp: «No video formats found»). Playwright-запасной загрузчик перехватывал аудиодорожку DASH как .mp4, ffmpeg не находил видеопотока (60 строк «Output file does not contain any stream»), разбор шёл только по звуку без картинок.
- Фикс: `fetch.has_video_stream` (ffprobe); файл без видеопотока удаляется, цепочка идёт дальше к gallery-dl, который отдаёт jpg слайдов (карусель/фото разбираются через OCR). Тесты 124.
- 11 затронутых карточек сброшены в `new` для переразбора run_all (подхватит со следующей пачки).
- Для будущего (S3/S4, подписки и «Похожие»): у сохранёнок конверсия в заметку высокая, у чужих аккаунтов она будет ниже, поэтому там нужен отдельный отбор (предфильтр по теме/активности до скачивания), порог и промпт нельзя переносить один в один.
