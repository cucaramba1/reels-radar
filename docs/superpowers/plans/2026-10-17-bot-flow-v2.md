Кнопки: 📝 заметка | 🎬 идея для рилса | ✨ вдохновение | 👥 друзьям (= отклонить) | ❌ отклонить. Только эмодзи, расшифровка в /help.
- 📝 -> [✅ предложенный холст] [🗂 другой холст] [➕ новый холст] [⬅️]. Нет раздела у темы: вместо ✅ кнопка «➕ создать «тема»».
- 🎬 -> показать структуру рилса -> [✅ принять] [✏️ править текстом] [⬅️]. Принятое пишется заметкой в «Контент и соцсети/Идеи для рилсов» (свой MOC + холст) и в базу.
- ✨ -> [🎨 визуал] [😂 мемы] [💡 идея] -> «Контент и соцсети/Вдохновение/{Визуал,Мемы,Идеи}», у каждого свой холст, общий холст «Вдохновение».
- После решения: [ℹ️ что выбрано] [↩️ Вернуть]. Вернуть = откат заметки (в .trash, строка MOC, нода холста) и карточка снова черновик.
- Структура рилса в карточке не показывается, пока не нажата 🎬.
- Холсты Досуга (Фитнес, Кулинария, Путешествия) лежат в vault «Obsidian Досуг»: Theme получает путь vault.
