# Спайк S1: чтение активности и «Похожих» с профиля Instagram

Дата: 2026-10-17. Объём: 13 открытий профилей и 1 клик по «Similar accounts», только чтение, пауза 6-10 с, один браузерный профиль `data/pw-profile` (Playwright, headless), без параллельных обращений. Скрипты в `scripts/spike_s1/` (одноразовые, как справка по селекторам).

## Что подтверждено
| Канал | Как читается | Проверено на |
|---|---|---|
| Посты, рилсы, коллабы | Ответ `api/graphql` с ключом `xdt_api__v1__feed__user_timeline_graphql_connection`: `edges[].node` с `taken_at` (epoch), `product_type` (`clips` рилс, `feed`, `carousel_container`), `coauthor_producers` (непустой = коллаб). Главная сетка уже содержит все три типа | mikhnesss (рилсы, 1 коллаб), 4chan.video (12 из 12 коллабов), 5.sens.production, money |
| Закрепы | Закрепы идут первыми и старые (money: 2016, 2018, затем 2026-04-07). **Брать максимум `taken_at` по всем узлам первой страницы, не первый элемент** | money |
| Число постов | `og:description`: «198K Followers, 4,057 Following, 2,895 Posts» | все; 21shavo_ = 0 Posts, ne.gor.e.gor = 3 Posts (3 даты 2017) |
| Активные истории | Аватарка внутри `[role=button]`, содержащего `canvas` (кольцо). Кружки хайлайтов тоже `canvas`, но снаружи этого контейнера: считать только кольцо аватарки | mikhnesss, 433: да; money, 5amoljen: нет |
| «Похожие» | `svg[aria-label="Similar accounts"]`, клик раскрывает блок «Suggested for you» (юзернейм, био-строка, кнопка Follow). Имена читаются из DOM ссылок блока; отдельного сетевого ответа не поймано | mikhnesss |

## Находки, меняющие решения
1. **Старый список «нет постов или закрытый» (598) в значительной мере неверен:** 3 из 3 проверенных (4chan.video, 5.sens.production, 5amoljen) активны, с постами 17.10, 17.10 и 12.10. Старый метод не дожидался загрузки сетки. Весь список остаётся в очереди проверки без доверия.
2. Запрос с датами 17.10 в `graphql/query` это **главная лента других аккаунтов** (ключ `xdt_api__v1__feed__timeline__connection`), его нужно игнорировать.
3. Сессия, скопированная из старого `ig_state.json` в новый браузерный контекст, **умерла на сервере** (редирект на вход, `is_from_rle`), причина неизвестна (параллельные клиенты или защита). После входа человека в отдельном окне и работы через тот же профиль браузера проблем нет. Правило: один клиент в момент времени, один постоянный профиль.
4. Редирект на вход принимать за смерть сессии, не за свойство аккаунта: останавливать сбор.

## Не проверено
- Закрытый профиль (нет образца среди проверенных): признак «This account is private» не подтверждён, до подтверждения закрытым считать профиль, у которого в шапке posts > 0, а ответа ленты нет и текст содержит private/закрыт; иначе ошибка `NO_TIMELINE` (unknown, не кандидат).
- Удалённый аккаунт (`NOT_FOUND`): текст страницы, не наблюдался.
- Список подписок чужого аккаунта (для 3 уровней): не исследован, самый рискованный запрос. Первые 2 уровня обходятся через «Similar accounts».
- Реальная производительность и безопасный дневной бюджет: темп ~10-14 с на профиль, 630 аккаунтов в очереди проверки = ~2-3 часа чистого времени. Бюджет на сутки задаётся конфигом, старт 60.

## Дизайн читателя профиля (для следующего плана)
Чистые функции, тестируемые на сохранённых ответах: `parse_timeline(json) -> list[Node]`, `parse_meta(text) -> (followers, following, posts)`, `build_activity(nodes, meta, ring, flags) -> Activity` (last_post = max по `feed`/`carousel_container` без коллабов, last_reel = max по `clips`, last_collab = max по узлам с `coauthor_producers`; `story_active` из кольца; `posts_count` из шапки; `channels` = все четыре, если лента или нулевой posts_count получены). Тонкий слой Playwright: один постоянный профиль, ожидание ответа ленты (до 12 с), остановка на редиректе на вход/429/403/challenge.
